Four things the filter never trusts

  • Urgent deadlines

    “Act now or your account is blocked.” Pressure is the oldest scam trick, and the model treats it as a warning sign.

  • Too-good prizes

    Lotteries you never entered and rewards that need a small fee first. If it sounds too good, it is usually a scam.

  • Mystery links

    Shortened links, odd domains and “click to verify” buttons are where most scam messages want you to go.

  • Secret requests

    OTPs, PINs and KYC details are never something a real bank asks for over SMS or chat.

From text to verdict

  1. 01

    Paste it in

    You drop in a message, say whether it is English or Hinglish, and where it landed: SMS or WhatsApp.

  2. 02

    Send it over

    The page posts the message, language and source as JSON to the FastAPI /predict endpoint.

  3. 03

    Run the pipeline

    The saved scikit-learn pipeline in SpamSMS.pkl turns the text, language and source into features.

  4. 04

    Score each class

    The model gives a probability to legit, spam and scam. The three add up to 100%.

  5. 05

    Verdict out

    The highest score wins. You see the label and the confidence for all three, right here on the page.

Ask the filter

Is my message saved?

The API in this project only reads your message, returns a prediction and moves on. Nothing in the code stores it.

Which languages work?

English and Hinglish, which is Hindi written with English letters. Pick one in the dropdown before you check.

What do legit, spam and scam mean?

Legit is a normal message, spam is unwanted promotion, and scam is an attempt to trick you out of money or personal details.

Is it always right?

No model is. Treat the verdict and percentages as a strong hint, and never share an OTP or tap a doubtful link just because it says legit.

How do I run it?

Keep index.html next to app.py, serve it from the / route, and start the server with uvicorn app:app --reload. Then open http://127.0.0.1:8000.

Can I call the API directly?

Yes. POST JSON with clean_message, language and source to /predict and you get back a prediction and the class probabilities.
